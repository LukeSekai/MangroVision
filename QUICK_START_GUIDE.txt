MANGROVISION QUICK START (CURRENT FASTAPI + REACT APP)

For a fresh clone on another laptop, follow docs/groupmate-setup.md first.
The orthophoto GeoTIFF, canopy checkpoint, and private .env settings do not
come from Git. The old START_MANGROVISION.bat starts the historical Streamlit
application and is not the current workspace.

After completing setup, run from the repository root in PowerShell:

  .\venv\Scripts\python.exe scripts/check_groupmate_setup.py
  .\venv\Scripts\python.exe MangroVision_New/start_dev.py

Open http://localhost:5173. To check database and storage readiness:

  .\venv\Scripts\python.exe scripts/check_groupmate_setup.py --online

Stop with Ctrl+C or:

  .\venv\Scripts\python.exe MangroVision_New/start_dev.py --stop
