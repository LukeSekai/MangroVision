===============================================================
MANGROVISION QUICK START
===============================================================

START
1. Double-click `START_MANGROVISION.bat`
2. Wait for the tile server and Streamlit app to start
3. Open `http://localhost:8502` if the browser does not open automatically

MANUAL START
1. Terminal 1:
   `venv\Scripts\python.exe start_tile_server.py`
2. Terminal 2:
   `venv\Scripts\python.exe -m streamlit run app.py --server.port 8502`

STOP
1. Double-click `STOP_MANGROVISION.bat`
2. Or press `Ctrl+C` in the tile-server and Streamlit terminals

PORTS
- Tile server: `8080`
- Streamlit UI: `8502`

FILES THAT MATTER
- `app.py`
- `start_tile_server.py`
- `planting_database.py`
- `waypoint_export.py`
- `canopy_detection/`
- `forbidden_zones.geojson`
- `eroded_zones.geojson`
- `planting_zones.db`
- `MAP/FINAL MAP`
- `models/`
